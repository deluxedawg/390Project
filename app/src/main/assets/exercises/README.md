Fatigue Training exercise demo clips.

Drop a looping clip named after each exercise's slug (see `FatigueExercises.java`) directly in
this folder — either a `.gif` (e.g. `squats.gif`) or an `.mp4` (e.g. `squats.mp4`). If both
exist for the same slug, the GIF wins. Any exercise without a matching file here just shows
the text prompt with no demo — nothing else needs to change in code.

Slugs currently used: jumping_jacks, high_knees, butt_kicks, run_in_place, burpees, plank,
situps, mountain_climbers, russian_twists, bicycle_crunches, squats, lunges, wall_sit,
calf_raises, jump_squats, pushups, tricep_dips, arm_circles, plank_shoulder_taps,
diamond_pushups.

Keep clips short (a few seconds, looping) and small — they ship inside the APK.
